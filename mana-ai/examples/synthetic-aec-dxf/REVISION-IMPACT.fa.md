# گزارش داخلی اثر بازنگری | نمونهٔ ساختگی

```sh
node mana-ai/src/native/synthetic-dxf-revision-impact.cjs markdown
node mana-ai/src/native/synthetic-dxf-revision-impact.cjs json
node --test mana-ai/tests/synthetic-dxf-revision-impact.test.cjs
```

ابزار فقط همان سه DXF آزمایشیِ نسخه‌بندی‌شده را از محل ثابت، با هش ثابت، می‌خواند. هر مقایسه به رسیدهای محاسبهٔ دقیق پلان/نما و نسخه و شناسهٔ بازشوی 21 متصل می‌شود. صفت «پنجره» صرفاً فرض سناریو است؛ هندسهٔ بازشو اندازه‌گیری شده، اما نوع، مصالح، تجهیزات، بازشو در واقعیت و تصمیم طراحی از CAD تشخیص داده نشده‌اند.

موتور موجود مانا از روی یک **مدل اعلام‌شدهٔ وابستگی‌ها** تأثیر را در هفت مسیر نشان می‌دهد: متره، هزینه، تدارکات، زمان‌بندی، قرارداد، دفترچه و شرح بصری. به‌هم‌خوردن پیوند مستقیم و اثر غیرمستقیم جدا نشان داده می‌شوند. فقط دو منبع پلان/نما واقعی‌اند و فایل‌های ساختگی آزمون هستند؛ داده‌های پایین‌دستی ثبت‌های فرضی‌اند، نه اسناد منتشرشده. پلان ثابت می‌ماند. مراجع BIM، مکانیک، برق و فضای داخلی طبقهٔ دیگر در این گراف به تغییر نمای نمونه متصل نیستند؛ این وضعیت دربارهٔ پروژهٔ واقعی یا نبود تداخل هیچ ادعایی ندارد.

این ابزار هیچ فایل، نقشه، رندر، برآورد، سفارش، مدت، دستورکار، وضعیت تأیید یا دسترسی را تغییر نمی‌دهد؛ فقط گزارش بازبینی را در stdout می‌نویسد. از پروندهٔ خصوصی، اینترنت، GPU یا مدل زبانی استفاده نمی‌کند. نتیجهٔ سنجش هندسی را برای تغییر قراردادی، مبنای قیمت، اجرای حرفه‌ای یا انتشار به کار نبرید.
