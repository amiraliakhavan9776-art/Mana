# فایل‌های بازتولیدشدهٔ بازبینی | فقط نمونهٔ ساختگی

مانا از **همان سه DXF سنجاق‌شده** یک CSV دقیق و یک SVG مقایسه‌ای تولید می‌کند. فایل‌های ورودی فقط‌خواندنی‌اند. این فایل‌های تازه، گزارش و تصویر بازبینی‌اند؛ مترهٔ قراردادی، نقشهٔ اجرایی، مدل BIM، رندر طراحی یا به‌روزرسانی اسناد پایین‌دستی نیستند.

- **CSV:** هجده ردیف شامل R1، R2 و دلتا، با واحدهای دقیق m² و mm²، شمارهٔ لایه/عنصر، هش فایل/هندسه و شناسهٔ گزارش. منفی بودن دلتا به‌معنای دستورکار یا کسور قراردادی نیست.
- **SVG:** دو نمای هم‌مقیاس با مختصات میلی‌متری، محدودهٔ افزایش بازشوی 21 و پلان بدون تغییر. انگلیسی بودن برچسب SVG برای نمایش باثبات؛ گزارش متنی بازبینی فارسی جداست. این SVG هیچ تصویر، قلم، اسکریپت یا پیوند بیرونی ندارد.
- **سند هش:** مسیر مرجع تغییر، هش منابع R1/R2 و شناسه و هش دو فایل بازبینی را می‌گوید. هش، امضا یا تأیید انسانی نیست.

فرمان فقط در stdout می‌نویسد. برای تمرین از پوشهٔ **تازه** استفاده کنید:

```sh
d="$(mktemp -d)"
tool=mana-ai/src/native/synthetic-dxf-review-artifacts.cjs
node "$tool" csv > "$d/review.csv"
node "$tool" svg > "$d/review.svg"
node "$tool" manifest > "$d/review.manifest.json"
python3 -B mana-ai/tools/verify_synthetic_dxf_review.py   "$d/review.csv" "$d/review.svg" "$d/review.manifest.json"
```

راستی‌آزما دوباره DXF اصلی، CSV و هندسهٔ برداری SVG را جداگانه می‌خواند. سطح کف L را از مساحت مستطیل منهای بریدگی محاسبه و بازشوهای مستطیلی را از گوشه‌های واقعی اندازه می‌گیرد. نتیجهٔ بازخوانی: کف ثابت ۴۰۲، خالص نما از ۲۰۷ به ۲۰۵٫۵ و تغییر ‎−۱٫۵ متر مربع. در SVG فقط بازشوی 21 میان دو نسخه تغییر می‌کند. نوع بازشو در این مثال «پنجره» فرض شده، نه استنباط از DXF.

```sh
node --test mana-ai/tests/synthetic-dxf-review-artifacts.test.cjs
```

کد به Node.js و راستی‌آزما به Python 3 استاندارد نیاز دارند؛ آزمون از پوشهٔ موقت استفاده می‌کند. هیچ دادهٔ خصوصی، مدل زبانی، شبکه یا GPU در این تمرین مصرف نمی‌شود. فایل‌ها برای اجرا یا ارائهٔ رسمی نیستند.
