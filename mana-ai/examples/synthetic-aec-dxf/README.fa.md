# آزمون ورودی DXF پلان و نمای جنوبی | فقط دادهٔ ساختگی

این نمونه سه **فایل واقعی DXF** را از دیسک می‌خواند: یک پلان کف ثابت و دو بازنگری یک نما. مسیر خروجی ندارد؛ گزارش JSON در stdout چاپ می‌شود. فایل‌های ورودی تغییر نمی‌کنند. این یک نمونهٔ محدود پذیرش برای مترهٔ هندسی و تشخیص تغییر است، نه مدل کامل پروژه، طراحی اجرایی فاز دو، BIM یا مترهٔ قابل پرداخت.

## چگونه اجرا شود

از ریشهٔ بستهٔ آزمایشی و با Node.js 20 یا بالاتر:

```bash
P="$PWD/mana-ai/examples/synthetic-aec-dxf"
node mana-ai/src/native/synthetic-aec-dxf.cjs inspect R1 \
  "$P/floor-r1-r2.dxf" "$P/south-facade-r1.dxf"
node mana-ai/src/native/synthetic-aec-dxf.cjs compare \
  R1 "$P/floor-r1-r2.dxf" "$P/south-facade-r1.dxf" \
  R2 "$P/floor-r1-r2.dxf" "$P/south-facade-r2.dxf"
node --test mana-ai/tests/synthetic-aec-dxf.test.cjs
```

| کنترل مستقل از کد | R1 | R2 |
| --- | ---: | ---: |
| کف L: ‎۲۴×۱۸−۶×۵ | ۴۰۲ متر مربع | ۴۰۲ متر مربع |
| گسترهٔ ناخالص نما: ‎۲۴×۹ | ۲۱۶ متر مربع | ۲۱۶ متر مربع |
| بازشوی اول (شناسهٔ DXF: 21) | ۶ متر مربع | ۷٫۵ متر مربع |
| بازشوی دوم (22) | ۳ متر مربع | ۳ متر مربع |
| سطح هندسی نما پس از کسر بازشوهای صریح | ۲۰۷ متر مربع | ۲۰۵٫۵ متر مربع |

تغییر خالص نما ‎−۱٫۵ متر مربع است. فقط هندسهٔ بازشوی 21 تغییر کرده است. فایل نمای R2 هش دیگری دارد، اما عناصرِ ثابت هش عنصریِ یکسان دارند. هر ردیف منبع، لایه، شناسهٔ DXF و هش هندسهٔ خودش را دارد. دوبرابرِ سطح از ضرب‌های صحیح شو‌لیس محاسبه و با انتگرال نوارهای افقی دوباره کنترل می‌شود. مساحت دقیق در میلی‌متر مربع و متر مربع به شکل رشتهٔ اعشاری می‌آید؛ گردکردن، نرخ، قیمت و پرت در کار نیست. گزارش تغییر هر دو گزارش را از **خود فایل‌ها** دوباره می‌سازد، نه از عددِ ارسالی کاربر.

## دامنهٔ پذیرش

فقط پروفایل کوچک آزمایشی ASCII DXF R2000 (`AC1015`) با سرآیند فقط دو متغیر و بخش `ENTITIES` پذیرفته می‌شود. مقدار `$INSUNITS=4` و مختصات صحیح، نامنفی و محدود به ۱۰۰٬۰۰۰ میلی‌متر الزامی‌اند. یک مرز سادهٔ قائم‌الزاویه در لایهٔ `FLOOR_OUTLINE` و یک مستطیل نما به‌همراه بازشوهای مستطیلی صریح در لایه‌های `FACADE_OUTLINE` و `OPENING_CONFIRMED` لازم‌اند. نقش «تأیید شده» در این نام لایه فقط قرارداد ساختگی این دادهٔ آزمون است و تأیید مهندسی یا قراردادی نیست. مرز جنوبی پلان باید یک خط یکتا در y=0 باشد و بازهٔ x با پای نمای جنوبی برابر باشد.

نبود واحد، ابهام یا مغایرت، بازشوی نامشخص، بازشوهای هم‌پوشان، چندضلعی خودمتقاطع، قوس، بلوک، پیوند خارجی و هر هندسهٔ خارج از این پروفایل کل گزارش مقدار را متوقف می‌کند. نوع توجه و حدود پشتیبانی از [DXF LWPOLYLINE](https://help.autodesk.com/cloudhelp/2024/ENU/AutoCAD-DXF/files/GUID-748FC305-F3F2-4F74-825A-61F04D757A50.htm) و [متغیرهای سرآیند DXF](https://help.autodesk.com/cloudhelp/2026/ENU/AutoCAD-DXF/files/GUID-A85E8E67-27CD-4C59-BE61-4DC9FADBE74A.htm) گرفته شده، اما این ابزار واردکنندهٔ عمومی AutoCAD، DXF، DWG، PDF اسکن‌شده یا IFC نیست. پیوند تعبیه‌شده دنبال نمی‌شود؛ محتوای ناشناخته پذیرفته نمی‌شود. ورودی بدون تأییدِ بازشوی صریح به معنای «بازشو صفر» نیست.

## برنامهٔ مقیاس حدود پنج‌هزار متر مربع، نه گزارش پروژه

۱۲ ارجاع برنامه‌ریزی `ARCH-L01` تا `ARCH-L12` به **همان نمونهٔ ۴۰۲ متر مربعی**: ‎۱۲×۴۰۲=**۴٬۸۲۴ متر مربع** (حدود ۵٬۰۰۰). فقط یک هندسهٔ پلان و یک نمای جزئی آزمایش شده‌اند؛ ۱۲ طبقهٔ ترسیم‌شده یا اندازه‌گیری‌شده وجود ندارند. این مساحت تکراری وارد گزارش مقدار نمی‌شود و دادهٔ بودجه، قرارداد یا ساخت نیست.

| مرجع بین‌رشته‌ای برای مرحلهٔ بعد | وضعیت |
| --- | --- |
| `ARCH-L01…L12`، `FACADE-SOUTH-001` | مراجع برنامه‌ریزی جدا؛ این نمونه فقط یک مرز/نما را می‌خواند |
| `BIM-GRID-001`، `BIM-LEVELS-001` | جای‌نگهدار تطبیق محور/تراز؛ هیچ مدل IFC یا برخوردسنجی اجرا نشده |
| `MECH-HVAC-001`، `MECH-PLUMB-001` | جای‌نگهدار مکانیک؛ بدون جداول سایز، مسیر یا محاسبات |
| `ELEC-POWER-001`، `ELEC-LIGHT-001` | جای‌نگهدار برق؛ بدون طراحی تابلو، مدار یا روشنایی |
| `INT-WALL-FINISH-001`، `INT-FLOOR-FINISH-001` | جای‌نگهدار دیتیل داخلی؛ بدون نقشه یا مترهٔ اجرایی |
| `FACADE-SUBFRAME-001`، `FACADE-DETAIL-001` | جای‌نگهدار دیتیل فاز دو؛ بدون طراحی اتصال، آب‌بندی یا کنترل سازه |

کار آزمایشی بعد فقط پس از تأیید این نمونه: ابتدا یک جفت پلان/نمای بی‌نام و محلی با واحد، برداشت تراز، محور مشترک، شمارهٔ بازنگری و بازشوهای صریح؛ سپس مقایسه با خروجی مستقلی که نیروی فنی از همان فایل‌ها سنجیده است. پیش از دادهٔ خصوصی، باید فرمت واقعی تعیین و در ورود فقط‌خواندنی جدا، دسترسی و نگهداری مستند شود. ضوابط، طراحی و خروجی قابل ساخت نیازمند کنترل افراد صلاحیت‌دارند.
