# گزارش آزمایشی سطح ناخالص

این ابزارِ فقط‌خواندنی، سطح هندسی یک مستطیل یا ذوزنقهٔ تخت را با ابعاد واردشده محاسبه می‌کند. گزارش فارسی Markdown یا JSON به خروجی استاندارد می‌رود؛ ابزار به اینترنت متصل نمی‌شود، فایل یا ادعای تازهٔ مأموریت نمی‌سازد و چیزی را فعال یا منتشر نمی‌کند.

## پیش‌نیاز

- Node.js 24 و کد سازگار با نسخهٔ اجراکنندهٔ رسید ناسا.
- **همان پوشهٔ خصوصی اصلی** که آزمون مستقیم پیشین ناسا در آن ۱۶ از ۱۶ شده است؛ همراه با فایل‌های اصلی آن. پوشهٔ تازه یا کپی‌کردن رسید کافی نیست. مسیرها باید کامل و بدون بخش‌های نسبی باشند.
- مسیر مطلق Python مانند مسیر نصب آزمایشی قبلی. برای گزارش، فقط مسیر در تنظیمات رسید استفاده می‌شود؛ برنامهٔ تازهٔ Python اجرا نمی‌شود.
- منبع آموزشی [Area، NASA Glenn](https://www.grc.nasa.gov/www/k-12/airplane/area.html): فقط نسخهٔ بررسی‌شدهٔ قبلی پذیرفته می‌شود. رسید یا منبع نامعتبر/ناموجود، گزارش مقدار تولید نمی‌کند (`NASA_QUANTITY_SOURCE_UNVERIFIED`).

## نمونه

از ریشهٔ مخزن و با جایگزینی دو مسیر در دستور اجرا کنید:

```bash
node mana-ai/research-preview/nasa-quantity-report.cjs \
  /absolute/original-nasa-workspace /absolute/python3 markdown \
  '{"shape":"trapezoid","unit":"mm","parallel_base_a_mm":7,"parallel_base_b_mm":2,"perpendicular_height_mm":3}'
```

نتیجه: **۱۳٫۵ میلی‌متر مربع = ۰٫۰۰۰۰۱۳۵ متر مربع**، بدون گردکردن. جای دو قاعدهٔ موازی قابل تعویض است؛ ارتفاع باید **فاصلهٔ عمود** بین دو قاعده باشد، نه طول ضلع مورب. برنامه از روی اعداد نمی‌تواند تشخیص دهد ورودی واقعاً از محل اندازه‌گیری شده یا درست برچسب خورده است.

برای مستطیل و خروجی قابل استفاده در برنامه‌ها:

```bash
node mana-ai/research-preview/nasa-quantity-report.cjs \
  /absolute/original-nasa-workspace /absolute/python3 json \
  '{"shape":"rectangle","unit":"mm","base_mm":3000,"perpendicular_height_mm":4000}'
```

نتیجه: **۱۲ متر مربع**. همهٔ ابعاد باید عدد صحیح از ۱ تا ۱۰۰٬۰۰۰ میلی‌متر باشند؛ متر، سانتی‌متر، رشتهٔ عددی و فیلد اضافی پذیرفته نمی‌شود. خروجی JSON مقدارهای اعشاری را به‌صورت رشته‌های دقیق، و صورتِ دوبرابرِ مساحت را با مخرج ۲ گزارش می‌کند.

## حدود و ممیزی

- هر گزارش شناسهٔ نسخهٔ فرمول، هش منبع و مدرک، و هش محتوای خودش را دارد. شناسه نشانهٔ یکپارچگی است، نه امضای دیجیتال یا مجوز انتشار.
- عدد ۱۶ از ۱۶ مربوط به **آزمون قبلی ذوزنقه** است، نه نتیجهٔ آزمون مستطیل، داده‌های ساختمانی کاربر یا تأیید مهندسی. خود گزارش با حساب دقیق بومی تولید و جداگانه بازکنترل می‌شود؛ نامزدِ آزمایشی قبلی برای مقدار گزارش اجرا یا فعال نمی‌شود.
- این ابزار فقط سطح هندسی **ناخالص** محاسبه می‌کند؛ کسورات، سطح خالص، قرارداد، قیمت، مبلغ یا مقدار قابل پرداخت، تأیید نقشه، مقررات و طراحی سازه در دامنه نیست.
- آزمون اختیاری یکپارچه با نسخهٔ ثابت HTML ذخیره‌شده و نمایه/انتقال ساختگی اجرا می‌شود؛ این آزمون اثبات دریافت زنده از ناشر نیست:

```bash
MANA_NASA_REPORT_TEST_LESSON=/absolute/nasa-area.html \
  node --test mana-ai/research-preview/nasa-quantity-report.test.cjs
```
