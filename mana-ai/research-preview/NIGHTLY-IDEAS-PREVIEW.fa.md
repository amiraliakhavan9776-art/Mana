# پنل فقط‌خواندنی ایدهٔ آزمایشی مانا

این پیش‌نمایش فارسی فقط یک پیشنهاد برای بازبینی انسانی نشان می‌دهد. شرط نمایش این است که **کارزار اصلی یادگیری بومی** قبلاً هر دو مورد مجاز را گذرانده باشد و مانا بتواند همان رسیدها را دوباره اعتبارسنجی کند. وضعیت چسبانده‌شده یا کپیِ رسید، جایگزین این شواهد نمی‌شود.

در پنل، دلیل انتخاب، آزمون مستقلِ پیشنهادی، بخش‌های مرتبطِ سند مادر و شناسهٔ مدرک دیده می‌شود. در این نمونه هیچ بهبود تازه‌ای نسبت به آخرین نسخهٔ پذیرفته‌شده اندازه‌گیری نشده است. آزمون و نگاشت پیشنهادی به سند هنوز نیازمند بازبینی‌اند و به صف اضافه نشده‌اند.

## مشاهدهٔ آزمایشی

از Node.js 24 و نسخهٔ کد سازگار با کارزار اولیه استفاده کنید. مسیرهای مطلقِ **همان** پوشهٔ کارزار، **همان** پوشهٔ رسیدهای بومی و همان نسخهٔ سند مادر لازم‌اند. فرایند پیش‌نمایش باید همان شناسهٔ کاربری مجاز برای خواندن پوشه‌های خصوصی را داشته باشد. آن‌ها را جابه‌جا نکنید و مجوزهایشان را بازتر نکنید.

در یک ترمینال خصوصی، یک رمز تصادفی ۶۴رقمی هگزادسیمال برای همین نشست بسازید و در مرورگر نگه‌ دارید. رمز را در پیوند، آرگومان خط فرمان، گیت، پیام یا لاگ قرار ندهید. نمونه برای Bash:

```bash
read -rsp 'MANA preview password: ' MANA_IDEAS_PREVIEW_TOKEN; printf '\n'
MANA_IDEAS_PREVIEW_TOKEN="$MANA_IDEAS_PREVIEW_TOKEN" \
  node mana-ai/research-preview/nightly-ideas-preview.cjs \
  /absolute/original/campaign /absolute/original/native /absolute/master.txt 39784
unset MANA_IDEAS_PREVIEW_TOKEN
```

صفحه در `http://127.0.0.1:39784/` باز می‌شود. نام کاربری `mana` و رمز، همان رمز موقتِ همین نشست پیش‌نمایش است. برای موبایل، فقط از تونل SSH/Termius مجاز با همان پورت مقصد و مبدأ روی loopback استفاده کنید؛ پورت را عمومی نکنید. برای پایان، از همان ترمینال `Ctrl+C` بزنید.

اگر رسید ناقص، نامعتبر یا متعلق به محیط دیگری باشد، پیام «مدرک کامل تأیید نشد» نمایان می‌شود. صفحه هیچ کارزار یا آزمونی را شروع نمی‌کند، هیچ مسیر فعال‌سازی یا نوشتن ندارد و از اینترنت هیچ محتوایی نمی‌گیرد. بازبینی ممکن است ارزیابی قطعیِ رسیدِ موجود را در حافظه تکرار کند؛ عامل یادگیری و مأموریت تازه اجرا نمی‌شوند. تازه‌سازی و راه‌اندازی دوباره همان مدرک را نشان می‌دهد، نه پیشرفتِ تازه.

## آزمون محلی HTTP و CPU

```bash
MANA_IDEAS_TEST_MASTER=/absolute/master.txt \
  node --test mana-ai/research-preview/nightly-ideas-preview.test.cjs
```

با نسخهٔ دقیق و محلی سند، خود آزمون یک کارزار آزمایشی مستقل و موقت می‌سازد؛ پنل آن را فقط می‌خواند. بدون سند، آزمون‌های محافظ مسیر و احراز هویت اجرا می‌شوند و آزمون یکپارچه اجرا نمی‌شود.
