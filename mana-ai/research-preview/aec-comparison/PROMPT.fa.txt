این آزمون هشت‌موردی را با داده‌های کاملاً ساختگی حل کن. فقط یک پاسخ JSON معتبر بده؛ بدون متن اضافه، قالب Markdown یا واحد داخل رشتهٔ عدد. هیچ اطلاعات یا ابزار خصوصی لازم نیست.

سیاست آزمون: فقط سطح هندسی ناخالص یک شکل تخت، با همهٔ ابعاد مثبت، صحیح و صراحتاً به میلی‌متر پذیرفته می‌شود. حتی اگر تبدیل ممکن است، سانتی‌متر یا واحدهای مختلط را تبدیل نکن. برای ذوزنقه باید هر دو قاعدهٔ موازی و ارتفاع عمود موجود باشند؛ طول ضلع مورب جای ارتفاع عمود نیست. از محاسبهٔ سطح خالص، کسورات، مقدار قابل‌پرداخت یا تفسیر قرارداد خودداری کن. گرد نکن. مرجع آموزشی مشترک برای فرمول هندسی:
https://www.grc.nasa.gov/www/k-12/airplane/area.html
نشانی مرجع از قبل داده شده است؛ لازم نیست ادعا کنی آن را تازه خوانده‌ای یا مهندسی آن را تأیید کرده است.

قالب بسته:
شیء اصلی فقط دو کلید schema و results دارد. schema دقیقاً "MANA_AEC_COMPARISON_V1" و results آرایهٔ هشت ردیف، یکی برای هر شناسه است. هر ردیف دقیقاً این کلیدها را داشته باشد:
id, status, shape, inputUnit, dimensionsMm, formulaId, twiceAreaMm2, denominator, areaMm2, areaM2, sourceUrl, reasonCode

shape برای مستطیل "rectangle" و برای ذوزنقه "trapezoid" است. اگر status برابر "OK" بود:
- inputUnit دقیقاً "mm" و dimensionsMm آرایهٔ اعداد صحیح JSON به ترتیب تعریف بالا است.
- formulaId برای مستطیل "gross-planar-rectangle-v1" و برای ذوزنقه "gross-planar-trapezoid-v1" است.
- twiceAreaMm2 صورتِ دوبرابرِ مساحت (رشتهٔ عدد صحیح ASCII)، denominator عدد JSON 2 است.
- areaMm2 و areaM2 رشته‌های اعشاری دقیق ASCII هستند: نقطهٔ اعشار اگر لازم است؛ بدون صفرهای اضافهٔ انتهای اعشار، جداکنندهٔ هزارگان، توان یا گردکردن.
- sourceUrl دقیقاً نشانی مرجع بالا و reasonCode برابر null است.

اگر status برابر "ABSTAIN" بود، فقط id، status، shape و reasonCode مقدار داشته باشند و همهٔ فیلدهای دیگر null باشند. reasonCode یکی از این موارد است: WHOLE_MILLIMETERS_REQUIRED برای واحد غیرمیلی‌متر، MIXED_UNITS برای واحدهای مخلوط، PERPENDICULAR_HEIGHT_REQUIRED برای نبود ارتفاع عمود، OUT_OF_SCOPE برای درخواست سطح خالص/قابل‌پرداخت. هیچ مقدار آزمایشیِ جایگزین در ردیف نامعتبر پیشنهاد نکن.
