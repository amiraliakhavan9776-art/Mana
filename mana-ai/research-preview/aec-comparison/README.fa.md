# مقایسهٔ کوچک مانا و دستیارهای دیگر: مترهٔ سطح ناخالص

**آزمایش:** هشت مسئلهٔ کاملاً ساختگی، چهار محاسبهٔ دقیق و چهار موردی که باید به‌درستی متوقف شوند. این مقایسه کیفیت محاسبه، رعایت دامنه و قابلیت پیگیری نتیجه را می‌سنجد؛ نه هوش عمومی، کشف مستقل منبع، سرعت، یادگیری مدل، یا تأیید مهندسی.

۱. فقط متن کامل [دستور فارسی](PROMPT.fa.txt) را در یک گفت‌وگوی تازه به هر دستیار بده. جواب مرجع، کد آزمون‌گر یا فایل‌های خصوصی را نفرست.
۲. پاسخ JSON هر دستیار را در یک فایل متنی UTF-8 جدا ذخیره کن، بدون خطوط یا حصار Markdown. نام نسخه و وضعیت دسترسی به ابزارها را برای خودت یادداشت کن. مرجع از ابتدا برای همه یکسان است.
۳. فرمان‌های زیر را از ریشهٔ مخزن با **Node 24** اجرا کن:

~~~bash
D=mana-ai/research-preview/aec-comparison
node "$D/grade.cjs" ./answer-assistant-a.json
node "$D/grade.cjs" ./answer-assistant-b.json
node "$D/run-mana.cjs" fixture > ./answer-mana-local.json
node "$D/grade.cjs" ./answer-mana-local.json
~~~

آزمون‌گر امتیاز کل، مقدار، توقف‌های درست و ردپای ورودی، واحد، فرمول، منبع و دلیل را جدا می‌دهد. نام فیلد ناسازگار گزارش می‌شود، نه جواب مطلوب. FORMAT_REJECTED را جدا از ضعف حساب گزارش کن؛ برای پاسخ اولیه دوباره از دستیار نخواه آن را اصلاح کند. آزمون‌گر مستقل از موتور مانا مساحت را با مختصات و جمع دو مثلث و اعداد صحیح دقیق محاسبه می‌کند.

**مانای محلی:** حالت fixture همین ورودی‌های ساختاریافته را به موتور قطعی مانا می‌دهد؛ آزمون فهم متن فارسی یا خواندن زندهٔ منبع نیست. دلیل توقف‌های سیاستی را آداپتور ثابت تعیین می‌کند. اگر همان پوشهٔ اصلی رسید مستقیمِ تأییدشدهٔ ناسا در نصب خودت موجود است، حالت زیر رسید را به‌صورت فقط‌خواندنی بازاعتبارسنجی می‌کند؛ پوشهٔ تازه، رسید کپی‌شده یا نسخهٔ دیگری جایگزین نیست:

~~~bash
node "$D/run-mana.cjs" verified-receipt /absolute/original-nasa-workspace /absolute/python3 > ./answer-mana-revalidated.json &&
node "$D/grade.cjs" ./answer-mana-revalidated.json
~~~

حالت بازاعتبارسنجی دانلود تازه نمی‌کند و با مدرک نامعتبر متوقف می‌شود. موفقیت دستگاه آزمایش به معنی اجرای سرور اصلی نیست. زمان‌های گفت‌وگوی دستیار و محاسبهٔ محلی را مستقیم مقایسه نکن. مرجع [Area، NASA Glenn](https://www.grc.nasa.gov/www/k-12/airplane/area.html) صرفاً رابطهٔ هندسهٔ تخت را پشتیبانی می‌کند.
