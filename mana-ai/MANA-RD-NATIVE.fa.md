# آزمایش یادگیری بومی مانا از نمونه

این مسیر آزمایشی، موتور بومی یادگیری از نمونه را به فهرست بازبینی‌شدهٔ مأموریت‌های سند مادر **۱٫۱** متصل می‌کند. مانا مأموریت را به ترتیب فهرست انتخاب می‌کند، دلیل انتخاب و یادداشت‌های مرتبطِ فهرست را ثبت می‌کند، سپس از روی مثال‌های بازبینی‌شده یک قاعدهٔ عددی محدود پیشنهاد می‌دهد. فایل سند و بخش مربوطه با اثر انگشت ثابت بررسی می‌شوند. محتوا یا نتایج آزمون به پردازش یادگیرنده داده نمی‌شوند. آزمون‌ها بعد از تثبیت پیشنهاد، در ناظر مستقل از فرایند یادگیری اجرا می‌شوند.

- حوزهٔ این آزمایش: طول خالص قرنیز و حجم لایهٔ یکنواخت، با ورودی صحیح و واحد مشخص. برای هر مأموریت ۸ نمونهٔ آزمون از فهرست اولیه و ۱۶ بردار عددیِ کنارگذاشته‌شده داریم؛ این داده‌ها مصنوعی و جدا از داده‌های پروژه‌اند.
- یافتن یادداشت‌های مرتبط از یک فهرست ثابت، تحقیق زندهٔ وب یا تأیید مستقل منابع نیست. استنتاج یک قاعده از مثال، آموزش وزن‌های مدل نیست. این مسیر نه از مدل زبانی استفاده می‌کند، نه GPU، نه سرور HTTP و نه کلید API.
- حتی گذراندن آزمون‌ها مهارت را فعال نمی‌کند و مجوز تولیدی یا تأیید مهندسی نیست. تصمیم به پذیرش خودکار در صورت ابهام یا قطع جست‌وجو ممنوع است؛ تطابق در نمونه‌های محدود نیز اثبات یکتایی فرمول در همهٔ ورودی‌ها نیست.
- وضعیت این آزمایش در یک پوشهٔ خصوصی جدا نگه‌داری می‌شود. از پوشهٔ آزمایش‌های قبلی استفاده نکنید. اگر اجرا پس از ثبت شروع به‌طور نامعلوم قطع شد، با حذف رسید یا ساختن پوشهٔ جدید همان تلاش را به‌عنوان ادامه ثبت نکنید؛ ابتدا وضعیت را بازبینی کنید.

## پیش‌نیاز و آزمون عملی

Node.js 24، یک نسخهٔ جدا از کد، و فایل متنی موجودِ سند مادر لازم است. فایل سند داخل مخزن یا این بسته نیست و نیازی به ارسال آن وجود ندارد. این آزمون سرویس یا پورت جدید باز نمی‌کند و نسخهٔ در حال اجرا را جایگزین نمی‌کند.

در نسخهٔ جداگانهٔ همین شاخه، از ریشهٔ مخزن این دستور را اجرا کنید. مسیر نمونهٔ سند را با مسیر واقعی فایل `master.txt` موجود جایگزین کنید. برای مشاهدهٔ مجدد وضعیت، همان مسیر چاپ‌شدهٔ `WORKSPACE` را در `inspect` به‌کار ببرید.

```bash
(
  set -eu
  master=/absolute/path/to/master.txt
  test "$(sha256sum "$master" | cut -d' ' -f1)" = b9ce58b50834cbbeba50997998a937392bceba613905f611a99bf6df42277ce2
  w="$(mktemp -d /tmp/mana-native-rd.XXXXXXXX)"
  printf 'WORKSPACE=%s\n' "$w"
  node mana-ai/run-rd-native-synthesis.cjs inspect "$w" "$master"
  node mana-ai/run-rd-native-synthesis.cjs run "$w" "$master"
  node mana-ai/run-rd-native-synthesis.cjs run "$w" "$master"
  node mana-ai/run-rd-native-synthesis.cjs inspect "$w" "$master"
)
```

ترتیب مورد انتظار: `READY` در ابتدا، یک پیشنهادِ آمادهٔ بازبینی برای هر مأموریت، سپس `COMPLETE` فقط برای همین صف دو مأموریتی. یک تلاش نیمه‌تمام با پیشنهاد تثبیت‌شده فقط اجازهٔ ادامهٔ بررسی دارد و نباید کارگر دوباره اجرا شود. این مسیر فرمان فعال‌سازی ندارد.

آزمون مستقل کد در Node.js 24، بدون سند خصوصی:

```bash
node --test mana-ai/tests/mana-rd-native-synthesis.test.cjs
```

برای آزمون یکپارچهٔ اختیاری، همین آزمون را با `MANA_TEST_MASTER` برابر مسیر مطلق همان سند واقعی اجرا کنید. فایل‌های آزمون برای بازبینی در مخزن موجودند، اما فقط پردازش ناظر می‌تواند آن‌ها را بخواند؛ در اجرای آزمون، دسترسی کارگر به پروندهٔ ارزیابی عمداً رد می‌شود. از ۱۶ بردار کنارگذاشته‌شدهٔ حجم، یک بردار جابه‌جایی محورهای یک نمونهٔ یادگیری است؛ این مورد آزمون تقارن است، نه یک ترکیب اندازهٔ تازه.
