# مساحت خالص کف | نسخهٔ آزمایشی

محاسبهٔ قطعی برای کف مستطیلیِ ساده، بدون مدل، شبکه، قیمت‌گذاری یا تصمیم اجرایی.
این پیاده‌سازی مهندسی است؛ از پیشنهادهای ناموفق مدل استفاده نشده و وزن مدل تغییر نکرده است.
رابط فارسی، نمونهٔ خط فرمان با جمله‌های قالب‌دار است؛ به‌معنی اتصال به رابط وب یا تشخیص آزاد متن نیست.

```bash
node --test tests/floor-takeoff*.test.cjs
node floor-takeoff-fa.cjs 'مساحت خالص کف مستطیل، طول ۵ متر، عرض ۴ متر، مساحت کسرشده ۳ مترمربع'
```

مساحت کل ۲۰ و مساحت خالص ۱۷ مترمربع است. اگر مساحت کسرشده ندارید، صریحاً «بدون کسر» بگویید.
در صورت ناقص بودن مقدار یا واحد، ابزار محاسبه نمی‌کند و فیلدهای لازم را می‌گوید؛ درخواست کامل را دوباره بفرستید.
می‌شود اعداد فارسی، عربی یا انگلیسی و جداکنندهٔ اعشار نقطه یا «٫» به کار برد. کاما، ممیز مورب و جداکنندهٔ هزارگان به‌عنوان عدد پذیرفته نمی‌شوند.

ورودی هسته: دقیقاً سه فیلد طول و عرض به متر و سطح کسرشده به مترمربع؛ هر سه رشتهٔ ده‌دهی غیرمنفی تا ۶ رقم اعشار.
طول و عرض از صفر تا ۱۰۰ و کسر از صفر تا ۱۰٬۰۰۰ است. دقت خروجی تا ۱۲ رقم اعشار بدون گرد کردن است.
خروجی منفی نیست؛ اگر کسری بیش از مساحت کل باشد، خروجی صفر و هشدار داده می‌شود.
تشخیص برچسب فیزیکی اشتباه بعد از اینکه یک عدد با واحد اعلام‌شدهٔ معتبر وارد شد، خارج از دامنه است.

این بسته مستقل است. فایل آزمایش‌های پیشین، تایمر، نسخهٔ فعال و دادهٔ پروژه را تغییر نمی‌دهد.
برای کنارگذاشتن آن، اجرای این پوشه را متوقف کنید؛ هیچ نصب یا ثبت سرویس انجام نشده است.
