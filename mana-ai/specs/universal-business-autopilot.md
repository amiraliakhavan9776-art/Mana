# Mana Business Autopilot — Universal Profession-Adaptive Operating System
Status: approved requirements; NOT implemented.

## Intent
After asking “What do you do?” Mana should discover the user's profession, organization type, size, location/jurisdiction, objectives, constraints and permissions, then propose and configure an end-to-end operating model tailored to that business. Construction is the first pilot, not a product limitation.

## Core process
1. Universal profession interview: ask only essential questions; adapt to business type and local rules.
2. Map departments, services, workflows, roles, regulatory requirements, documents, integrations and KPIs.
3. Create an editable proposed operating blueprint with priorities and implementation gaps.
4. Deploy scoped specialist agents (operations, finance, sales, HR, legal/contract support, R&D, strategy, branding, procurement, project management, creative tools, etc. as relevant).
5. Connect authorized data and tools, with tenant/project isolation, explicit data handling permissions and audit logs.
6. Autonomously draft, schedule, reconcile, monitor, communicate and execute low-risk permitted work; request authorized approval for high-impact, irreversible, financial, legal or safety-critical actions.
7. Detect exceptions, verify outcomes against evidence, report confidence and performance, and suggest/implement controlled improvements.
8. Allow self-development proposals in sandbox, tests and review; never unreviewed production code deployment or privilege escalation.

## Acceptance pilot
Given an architecture/construction firm profile, produce an organization blueprint, proposed agent roster, WBS, KPI dashboard specification, strategy and branding briefs, finance and site-reporting workflows, sample drafts and a permissioned action queue. Demonstrate that sensitive data is never disclosed across roles or projects. Do not claim that all workflows are executable until actual integrations are tested.

## Operational constraints
Iran-local independent core, optional authorized overseas GPU, no external API dependency for core operations, data minimization, least privilege, versioning, approvals and licensed professional sign-off as required.
