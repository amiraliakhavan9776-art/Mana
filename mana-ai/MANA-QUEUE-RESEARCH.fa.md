# اجرای آزمایشی «برو جلو» برای موتور پژوهش مانا

این پیش‌نمایش اختیاری یک آزمون از مأموریت موجود `88ab05d456850cd0` در صف ۸۴ ردیفی است. برای بندهای ۳٫۵ و ۳٫۶ سند ۱٫۱، مانا از فهرست ناشر به مستند می‌رسد، یک پیشنهاد محدود می‌سازد، آن را با نمونه‌های مستقل می‌سنجد و رسید را ذخیره می‌کند. وضعیت اصلی صف و ۸۳ ردیف خارج از محدوده تغییر نمی‌کند. سند خصوصی در مخزن نیست.

## اجرای جداگانه

از ریشهٔ یک checkout تازهٔ همین تغییر، با Node 24 و کاربر معمولی روی لینوکس:

```bash
node --version
state="$(mktemp -d)"
MANA_QUEUE_RESEARCH_PORT=8798 node mana-ai/research-preview/preview.cjs "$state" --official-https
```

روی همان دستگاه به `http://127.0.0.1:8798/` برو و «برو جلو» را بزن. اگر پورت اشغال است متغیر پورت را حذف کن تا نشانی آزاد در ترمینال نوشته شود. برای آزمون از دستگاه دیگر، فقط تونل خصوصی به نشانی محلی استفاده کن؛ پورت را عمومی نکن. این دستور هیچ سرویس موجودی را نصب، متوقف یا راه‌اندازی دوباره نمی‌کند. هنگام بستن پیش‌نمایش پوشهٔ خصوصی رسید را برای بازپخش بعدی نگه دار.

- با اجازهٔ شبکهٔ میزبان، گزینهٔ `--official-https` فقط سه مسیر ثابت مستندات را از `raw.githubusercontent.com` در commit رسمی ثابت CPython می‌خواند. تغییر مسیر، بدنهٔ بزرگ و شناسهٔ ناهماهنگ رد می‌شوند. مسیر نهایی فقط وقتی درخواست می‌شود که پیوند آن در فهرست ناشر دیده و تأیید شده باشد.
- برای بازپخش بی‌اینترنت، به جای `--official-https` مسیر مطلق پوشهٔ ثبت رسمی را بده. فایل‌های `index.rst.json`، `numeric.rst.json` و `math.rst.json` باید هرکدام شامل `repository`، `commit`، `path`، `gitBlobSha`، `url`، `retrievedAt` و `contentBase64` منطبق با قرارداد و پین‌های `cpython-source.cjs` باشند. محتوای ناشر در این PR تکثیر نشده. بازپخش آفلاین در رابط صریحاً برچسب می‌خورد.
- نتیجهٔ موفق «نیازمند بازبینی» است. دلیل انتخاب، پیوند دقیق سند و شمار آزمون‌ها در همان صفحه می‌آیند. اگر منبع در دسترس نباشد، پیشنهادی ساخته نمی‌شود. کلیک تکراری نتیجهٔ ثبت‌شده را برمی‌گرداند. اگر اجرای اولیه نیمه‌کاره بماند، از تکرار خودکار جلوگیری می‌شود؛ برای آزمایش تازه پس از رفع مشکل، پوشهٔ خصوصی تازه بساز و رسید قبلی را نگه دار.

## آزمون و حدود شواهد

```bash
node --test mana-ai/tests/research-preview.test.cjs
```

برای آزمون‌های مسیر موفق واقعی، `MANA_CPYTHON_OFFICIAL_CAPTURES` را روی فایل JSON مطلقی تنظیم کن که همان سه رکورد را با کلید مسیر نسبی ناشر دارد. بدون آن، چهار آزمون وابسته به مدرک واقعی عمداً اجرا نمی‌شوند؛ حالت‌های رد منبع و محدودیت مسیر، دکمهٔ فارسی و توقف امن بدون شبکه آزموده می‌شوند.

در آزمایش پذیرش، با اجرای کد واقعی دکمه روی HTTP محلی، میزبان بعد از هر درخواست مانا همان سند را از اتصال فقط‌خواندنی GitHub خواند. ترتیب درخواست ناشر: فهرست اصلی ← فهرست عددی ← مستند ریاضی. مانا رابطه را از متن ناشر استخراج کرد و پس از تثبیت پیشنهاد، ۱۶ آزمون مستقل اعداد صحیح را گذراند. مرجع ثابت آزمون از اجرای CPython 3.13.5 و محاسبهٔ مستقل ساخته شده است و در دسترس کارگر سازنده نیست. محیط آزمون خروجی مستقیم HTTPS نداشت؛ اتصال مستقیم روی سرور کاربر آزمایش نشده. آزمون UI اجرای JavaScript واقعی صفحه روی HTTP بود، نه مشاهدهٔ رندر در مرورگر کامل.

این یک مسیر محدود و نسخه‌بندی‌شده است، نه جست‌وجوی وب باز، برابری با محاسبات ممیزشناور پایتون، آموزش وزن مدل، یادگیری عمومی، فعال‌سازی مهارت یا انتشار. هیچ تغییر اجرایی روی سرور اعمال نشده.
