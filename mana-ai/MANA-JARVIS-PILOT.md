# مانا و جارویس | پذیرش نسخهٔ آزمایشی

این مرحله روی همان نسخهٔ آزموده‌شدهٔ PR #2 (`28d330cc920fb374e92651b46f8b9af86f194a3a`) ساخته می‌شود. در ۱۹ نوامبر ۲۰۲۶، کاربر در Safari آیفون دو بار «برو جلو» را زد: دو آزمون وابستگی‌های نوع‌دار و دو آزمون ذخیره و بازیابی قبول شدند و هر دو مأموریت در سابقه ظاهر شدند. این شاهد نسخهٔ پایه است، نه قبولی پیشاپیش این تغییرات.

معیار تحویل آزمایشی، اجرای هر مسیر از ورودی فارسی تا خروجی قابل بررسی روی دادهٔ ساختگی است. بازبینی انسانی قبل از هر انتشار یا جایگزینی فایل سرور لازم است. سند جامع MANA و Jarvis همچنان مرجع دامنه است؛ این پذیرش محدود جایگزین آن نیست.

| مسیر | نتیجه‌ای که باید ببینید | خارج از دامنهٔ این تحویل |
| --- | --- | --- |
| صورت‌هزینه | جمع دقیق، اختلاف با جمع اظهار‌شده، واحد پول صریح، ردیف‌های منبع و گزارش قابل دریافت | اعتبارسنجی اصل فاکتور، تأیید پرداخت، حسابرسی حقوقی یا مالیاتی |
| نقشه | فایل‌های DXF قابل‌ویرایش با واحد متر، ابعاد خوانا و هندسهٔ قابل بازکردن و بررسی دوباره | نقشهٔ اجرایی، طراحی سازه یا تأسیسات، کنترل ضوابط، DWG/IFC |
| جارویس | یک درخواست فارسی، برنامهٔ چندمرحله‌ای، کنترل شروع و دریافت فایل‌های واقعی | گفت‌وگوی عمومی، کنترل آزاد ابزارها و صدا مگر با آزمون جداگانه |

## ترتیب بازبینی

1. از checkout تازه و دادهٔ آزمایشی جدا استفاده کنید؛ روی پوشه یا دادهٔ سرویس فعال چیزی ننویسید.
2. یک اختلاف عمدی در جمع صورت‌هزینه وارد کنید. گزارش باید اختلاف را با ردیف‌ها و واحد درست نشان دهد. پس از اصلاح جمع، همان ورودی باید سازگار گزارش شود.
3. در جارویس برای زمین مستطیلی ۱۲ در ۲۰ متر دو گزینهٔ شماتیک، متره و دفترچه بخواهید. قبل از شروع، برنامه را ببینید. پس از پایان، فایل‌های قابل دریافت را باز کنید و ابعاد و واحد را دوباره بسنجید. این ابعاد فقط نمونهٔ آزمایشی‌اند.
4. رفتار درخواست نامعتبر، دوباره‌کلیک، تازه‌سازی و دسترسی به فایل ناموجود را هم بررسی کنید. نمایش برنامه یا پیش‌نمایش، گواه اجرای ابزار نیست.
5. نتیجهٔ آزمون روی CPU، آزمون مرورگر و آزمون سرور را جدا ثبت کنید؛ mock صدا یا مدل را به‌عنوان اجرای واقعی گزارش نکنید.

## اجرا در محیط جدا

این دستورها در checkout تازهٔ شاخهٔ این PR اجرا می‌شوند. پیش‌نیاز: Linux، Node.js 24 و Python همراه وابستگی‌های [`requirements-artifacts.txt`](tools/requirements-artifacts.txt). از محیط Python موجودی که همین وابستگی‌ها را دارد استفاده کنید، یا در یک venv تازه نصبشان کنید. برای دکمهٔ قدیمی «برو جلو»، پیش‌نیازهای Bubblewrap جداگانه در [راهنمای مرحلهٔ قبل](DEVELOPMENT-STAGING.md) آمده است. برای بررسی صورت‌هزینه و جارویس شماتیک نیازی به روشن کردن GPU نیست.

```sh
node --test mana-ai/tests/expense-pilot.test.cjs mana-ai/tests/jarvis-preview.test.cjs
python -m unittest discover -s mana-ai/tools -p test_schematic_plan.py
export MANA_DEVELOPMENT_WORKSPACE="$(mktemp -d /tmp/mana-mission-pilot.XXXXXXXX)"
export MANA_JARVIS_PREVIEW_WORKSPACE="$(mktemp -d /tmp/mana-jarvis-pilot.XXXXXXXX)"
MANA_DEVELOPMENT_PORT=8800 node mana-ai/development-ui.cjs
```

نشانی دقیق `http://127.0.0.1:8800/` است؛ روی آیفون یا رایانهٔ دیگر، در تونل SSH هم پورت محلی و هم پورت مقصد `8800` باشد. پورت مقصد آدرس `127.0.0.1` روی سرور است. پورت را عمومی نکنید. پورت متفاوت برای دست‌نخورده ماندن پایلوت قبلی روی ۸۷۹۸ انتخاب شده است. برای مشاهدهٔ سابقه بعد از توقف عادی، مسیرهای دادهٔ همان آزمایش را دوباره استفاده کنید.

ربط GPU به این مرحله محدود است: این سه مسیر اجرایی به GPU نیاز ندارند. آزمون مدل و صدای محلی باید کیفیت و زمان را جدا اندازه بگیرد. مشاهدهٔ نام GPU در `nvidia-smi` به‌تنهایی شاهد استفادهٔ مدل از آن نیست.
