# آزمایش جداگانهٔ مانا: یافتن یک منبع رسمی جایگزین

مأموریت مرتبط: «مترهٔ سطح ناخالص قطعهٔ ذوزنقه‌ای»، بند ۶٫۴ سند ۱٫۱، ردیف `6d213a1b0d0b2a93`. این شاخه صف اصلی، بودجهٔ تلاش‌های قبلی و رسیدهای INDOT را تغییر نمی‌دهد. آزمایش فعلاً از خط فرمان اجرا می‌شود و دکمهٔ «برو جلو» در پیش‌نمایش قبلی را عوض نمی‌کند.

مانا از [فهرست رسمی مرکز گلن ناسا](https://www.grc.nasa.gov/www/k-12/airplane/short.html) لینک درس «Area» را پیدا می‌کند؛ اگر منبع، دامنهٔ ادعا یا عبارت مربوط تأیید نشود، پیشنهادی نمی‌سازد. رابط آموزش فقط نمونه‌های برگرفته از همان عبارت را به موتور محدود بومی می‌دهد، نه فایل ناشر و نه پاسخ‌های آزمون مستقل. موتور عبارت پیشنهادی را می‌سازد و آزمون‌های مستقل روی CPU آن را می‌سنجند. این اجرای محدود به معنی جست‌وجوی آزاد در وب، آموزش وزن‌های مدل یا تأیید مترهٔ قراردادی و اجرایی نیست.

## اجرای آزمایشی

از ریشهٔ نسخهٔ آزمایشی مخزن، با Node.js 24 و Python 3 روی لینوکس اجرا کنید. نصب کتابخانهٔ Python یا استفاده از GPU لازم نیست. مسیر وضعیت باید تازه و جدا از رسیدهای قبلی باشد:

```sh
state="$(mktemp -d)"
node mana-ai/research-preview/nasa-area-experiment.cjs "$state" --direct "$(realpath "$(command -v python3)")"
```

برای دیدن نتیجهٔ ثبت‌شده همان مسیر `state` را نگه دارید. آزمون‌های قابل تکرار بدون دسترسی به ناشر:

```sh
node --test mana-ai/research-preview/nasa-*.test.cjs
```

قبولی آزمون با دادهٔ ساختگی، جایگزین دریافت واقعی از ناشر نیست. پیش‌نمایش، درس [Area](https://www.grc.nasa.gov/www/k-12/airplane/area.html) از NASA Glenn را فقط برای رابطهٔ هندسی دوبعدی بررسی می‌کند؛ ناسا متره یا پیشنهاد مانا را تأیید نکرده است.

- قبولی آزمون‌ها فقط به معنی آماده بودن پیشنهاد برای بازبینی است؛ ادغام، انتشار و فعال‌سازی انجام نمی‌شود.
- اگر اتصال به ناشر برقرار نشود، نتیجهٔ توقف ثبت می‌شود. این نتیجه را با قبولی آزمون یکسان نگیرید.
- نتیجهٔ معتبر از اجرای قبلی دوباره نشان داده می‌شود؛ بازکردن گزارش نباید باعث درخواست شبکه یا اجرای دوبارهٔ موتور پیشنهاد شود.
