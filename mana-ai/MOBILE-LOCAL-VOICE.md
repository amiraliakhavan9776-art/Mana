# Mana AI mobile voice — local speech route

The mobile UI now captures microphone audio using MediaRecorder, uploads WebM to `POST /api/voice/transcribe`, and plays WAV generated by `POST /api/voice/speak`. It no longer calls browser SpeechRecognition or speechSynthesis.

This is source-code integration only, not a deployed mobile app. Audio recording is limited to 15 seconds; the server limits uploads to 2 MiB. Unsupported browser formats leave the record button disabled. Device/browser behavior still needs testing.

Run tests (Node.js 20+):
```sh
node --test mana-ai/tests/mobile-local-voice.test.cjs mana-ai/tests/mobile-voice.test.cjs mana-ai/tests/local-voice-api.test.cjs
```

**Production prerequisites:** installed Persian ASR and TTS weights; verified compatible audio decoding; an authenticated HTTPS reverse proxy or private VPN; per-user authorization, CSRF defenses, quotas and audit; device testing on iOS and Android. The prototype listens only on 127.0.0.1 and is not reachable from another phone yet.

Never expose the unauthenticated development server to the public internet. No external voice provider is intentionally invoked by this code path, but privacy must be validated end-to-end after deployment.
