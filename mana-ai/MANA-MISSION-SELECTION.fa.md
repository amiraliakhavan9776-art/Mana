# مانا: انتخاب و اجرای دو آزمون پژوهشی از صف سند

در این پیش‌نمایش با یک دستور ثابت فارسی و دکمهٔ «برو جلو»، مانا خودش اولین ردیف واجد شرایط را به ترتیب صف نسخهٔ ۱٫۱ انتخاب می‌کند. فقط دو ردیف از صف ۸۴ ردیفی برای این آزمایش پشتیبانی می‌شوند:

1. موتور پژوهش، مستند رسمی CPython و یک قاعدهٔ عددی محدود (بندهای ۳٫۵ و ۳٫۶).
2. متره، مساحت ناخالص قطعهٔ ذوزنقه‌ای با شواهد راهنمای رسمی INDOT (بند ۶٫۴).

صف اصلی بازنویسی نمی‌شود. پس از قبولی مستقل و بازخوانی رسید همان نسخه، اجرای بعدی ردیف دوم را انتخاب می‌کند؛ با دو رسید معتبر، اجرای بعدی دلیل توقف را نشان می‌دهد و دوباره به سراغ منبع یا آزمون نمی‌رود. شکست، رسید دستکاری‌شده یا نتیجهٔ نامعلوم، مسیر را متوقف می‌کند و تکرار خودکار ندارد. رسیدها فقط گواه قبولی یک آزمون محدودند، نه تکمیل ردیف اصلی یا فعال‌سازی قابلیت.

## اجرا روی CPU

Node.js 24 یا بالاتر. پوشهٔ وضعیت خصوصی و خالی را جدا از کد و از ورودی‌ها بساز. برای راه‌اندازی واقعی به همان سند خصوصی `master.txt` و یک ثبت منبع بازبینی‌شدهٔ INDOT نیاز است؛ این ورودی‌ها در Git نیستند. CPython یا از طریق دریافت محدود مستقیم از ناشر گیت‌هاب، یا از سه ثبت بازبینی‌شده در یک پوشهٔ محلی خوانده می‌شود. INDOT فقط بازپخش پین‌شده است، نه دانلود زنده از سرور مانا. ثبت بازپخش باید از مسیر مجاز و خصوصی در اختیار آزمایشگر باشد؛ به عنوان جایگزین، آزمون بی‌نیاز از این ورودی‌ها در ادامه آمده است.

```bash
state="$(mktemp -d)"
node mana-ai/research-preview/mission-selection-preview.cjs "$state" \
  /path/to/private/master.txt --official-https \
  /path/to/private/indot-capture.json 8b034f442ac72023a658c8d9b2d08522e5c04d0abd67631bdd2b3649048228a4
```

به جای `--official-https` می‌توان مسیر مطلق پوشهٔ ثبت CPython (`index.rst.json`، `numeric.rst.json` و `math.rst.json`) را گذاشت. هش درج‌شده متعلق به ثبت تازهٔ بازبینی‌شدهٔ ۲۱ نوامبر است. با ثبت قبلی، هش قبلی `2d78ddee786ffcba28391e053ce2ef923ad70bb6de4d0a58d136e45a0f002b33` را بده؛ هش دلخواه پذیرفته نمی‌شود. نشانی محلیِ چاپ‌شده را باز کن. یک‌بار «برو جلو» بزن و نام، دلیل و نتیجه را ببین. دوباره با همان دستور بزن. برای آزمون ماندگاری می‌توان بین اجراها برنامه را با همان مسیرها و پوشهٔ وضعیت راه‌اندازی مجدد کرد. پوشه را جابه‌جا نکن. رابط فقط روی `127.0.0.1` گوش می‌دهد؛ برای دسترسی از دستگاه دیگر فقط از تونل خصوصی استفاده کن.

## آزمون

```bash
node --test mana-ai/tests/mission-selection*.test.cjs
```

آزمون مسیر واقعی CPU از دو منبع پین‌شده و سند خصوصی استفاده می‌کند. برای تکرار همین آزمایش، `MANA_TEST_MASTER`، `MANA_SELECTION_CPYTHON` و `MANA_SELECTION_INDOT` را به مسیرهای مطلق مجاز و `MANA_SELECTION_INDOT_SHA256` را به هش ثبت بازبینی‌شده تنظیم کن. بدون این ورودی‌ها، آزمون‌هایی که به آنها وابسته‌اند اجرا نمی‌شوند و نباید نتیجهٔ آنها را به GitHub یا سرور نسبت داد.
