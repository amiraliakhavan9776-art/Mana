# مانا: بازیابی دریافت منبع بعد از پایان مهلت

این پیش‌نمایش فقط برای یک حالت اجازهٔ بازیابی می‌دهد: ردیف اول رسید قبولی معتبر دارد، ردیف متره با روش مستقیم اجرا شده، و رسید معتبر آن می‌گوید دریافت از ناشر در مهلت مقرر تمام نشده و هیچ پیشنهاد یا آزمونی آغاز نشده است. در اجرای بعدی با همان فرمان «برو جلو»، **مانا خودش تشخیص می‌دهد** که باید یک‌بار همان دریافت محدود را تکرار کند. کاربر پیوند، فایل، فرمول یا فرمان جداگانه‌ای نمی‌دهد.

- اجرای قبلی پایتون و رسید نخست متره حفظ و بازخوانی می‌شوند. تلاش دوباره، رسید جدا و سقف یک‌بار دارد.
- باز کردن صفحه یا خواندن سابقه، دانلود تازه شروع نمی‌کند. اجرای هم‌زمان فقط یک تلاش دریافت می‌کند.
- اگر نسخهٔ PDF عوض شده، مدرک نامعتبر است، یا نتیجهٔ اجرای قبلی نامعلوم است، مانا دوباره اجرا نمی‌کند. بعد از تلاش مجاز هم تکرار خودکار دیگری ندارد.
- مسیر قبلی بازپخش از این امکان استفاده نمی‌کند. منبع همان ناشر رسمی است و بررسی‌ها، حدود فایل و هش ناشر عوض نشده‌اند.
- این بازیابی محدودِ دریافت یک منبع است، نه تغییر کد توسط مانا، تکمیل صف ۸۴ ردیفی، یا فعال‌سازی مهارت.

## اجرای جداگانه روی CPU

راهنمای [دریافت مستقیم](MANA-INDOT-DIRECT.fa.md) را برای Node 24، Python موجود با PyMuPDF، سند خصوصی و شیوهٔ اجرای روی loopback ببین. اگر رسیدهای نسخهٔ قبلی را داری، برنامهٔ قبلی را از **همان ترمینال آزمایشی** متوقف کن، پوشهٔ وضعیت را در همان نشانی حفظ کن و همان پوشه را به نسخهٔ جدیدِ بازبینی‌شده بده. پوشهٔ وضعیت را جابه‌جا، کپی یا خالی نکن. نسخهٔ اصلی سرور را تغییر نده.

```bash
node mana-ai/research-preview/mission-selection-preview.cjs /absolute/existing/state \
  /absolute/private/master.txt --official-https --indot-https /absolute/python-with-pymupdf
```

در صفحه باید قبولی قبلی پایتون یا رسید توقف متره قابل‌بازیابی باشد. با دستور پیش‌فرض «برو جلو» بزن. اگر شرایط بازیابی برقرار است، توضیح داده می‌شود که چرا مانا فقط سراغ دریافت مجدد متره رفته. اگر دریافت دوباره هم موفق نبود، همان نتیجه ثبت می‌شود؛ قبولی پایتون حفظ خواهد شد. برای نتیجهٔ نامعلوم پوشهٔ وضعیت را پاک نکن.

## آزمون

آزمون‌های رسید و رابط را روی CPU با Node 24 اجرا کن:

```bash
node --test mana-ai/tests/mission-selection*.test.cjs
```

بعضی آزمون‌های کامل به سند خصوصی و ثبت‌های ناشر نیاز دارند. آزمونِ بازیابی تزریقی، دریافت زنده روی سرور کاربر را اثبات نمی‌کند.
