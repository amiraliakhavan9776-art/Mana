Status vocabulary: tested prototype = selected synthetic tests; partial = some components exist; planned = no implementation acceptance in this branch; external-unverified = reported elsewhere, source/runtime not validated here.

## Order preserved from master section 14
1. Existing code/data audit, architecture, permissions/data and agent/core foundation.
2. Operational MVP: chat, document search, letters/minutes, workflow, dashboard and basic takeoff.
3. Project/financial/strategy/council/technical-office and CAD/BIM integrations.
4. Creative studios, broader autonomy, Jarvis, Wealth Engine and commercial readiness.

This increment implements isolated core planning/evaluation/memory components. It does not close the existing inventory/regression release gates or reorder advanced modules ahead of the required foundations.
Reported server branch/version names (including Core v5) remain distinct from this planning module v0.1 until actual source and integration tests establish compatibility.
